
🚀 Cognizant Interview Experience | Full Stack Java + Angular | 3+ Years  
  
One of my connections recently shared their interview experience after attending a Full Stack Java + Angular Developer interview at Cognizant.  
  
Reposting the questions to help fellow Java and Angular developers prepare for similar opportunities.  
  
💻 Java & Spring Boot  
  
1. Explain your current project, the modules you have worked on, and the deployment process.  
2. What are the main features introduced in Java 8?  
3. Interface vs Abstract Class.  
4. What is a default method in Java?  
5. What is the Stream API, and where have you used it?  
6. Difference between map() and flatMap().  
7. What is exception handling? How do you handle exceptions in your application?  
8. HashMap vs ConcurrentHashMap.  
9. Explain Spring Boot and why we use it.  
10. What is Dependency Injection in Spring?  
11. What is @SpringBootApplication?  
12. What is @ComponentScan?  
13. How do you create a REST API in Spring Boot?  
14. Authentication vs Authorization.  
15. How does JWT authentication work?  
  
🌐 HTTP & SQL  
  
16. Explain HTTP status codes: 200, 400, 401, 403, and 500.  
17. What is a JOIN? Explain INNER JOIN and LEFT JOIN.  
18. DELETE vs TRUNCATE vs DROP.  
19. UNION vs UNION ALL.  
20. Write a query to find the 5th highest salary from an Employee table.  
  
🅰️ Angular  
  
21. What is a Component in Angular?  
22. What are Directives? Explain the types of directives you have used.  
23. What is data binding? Explain the different types.  
24. How do you implement routing in Angular?  
25. How do you pass an ID while navigating from one component to another?  
26. Template-driven forms vs Reactive Forms.  
27. How do you share data between parent and child components?  
28. What is a Service in Angular, and why do we use it?  
29. If an API returns an array of employees, how would you call the API and display the data in a table?  
30. Your API works in Postman but not in Angular. What would you check?  
  
📌 Key Takeaway  
  
This interview covered both backend and frontend fundamentals, including Java 8, Spring Boot, REST APIs, JWT, SQL, Angular components, routing, forms, and API integration.  
  
For full-stack roles, be ready to explain how the frontend communicates with backend APIs, how authentication is handled, and how you troubleshoot issues across the application.
