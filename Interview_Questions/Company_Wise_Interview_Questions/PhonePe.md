PhonePe Interview Experience – Round 1 | System Integration Engineer | 2–4 YOE

Had my Round 1 interview with PhonePe today for the System Integration Engineer (2–4 YOE) role.

The round mainly focused on DSA and Microservices/REST API integration.

Questions asked:

1. DSA – First occurrence of substring: Given two strings, find the index of the first occurrence of the second string (substring) in the first string.
2. DSA – Good Substrings: Given a string, find the number of substrings of length 3 where all three characters occur exactly once, i.e., all 3 characters are distinct.
    Example: "abc" → good, "aab" → not good.
3. Microservices: What can be used to call another service’s API in a microservices architecture?
4. Coding: Write code using RestTemplate to call another microservice API.

Overall, the round was focused on problem-solving, REST APIs, and practical microservices concepts.
