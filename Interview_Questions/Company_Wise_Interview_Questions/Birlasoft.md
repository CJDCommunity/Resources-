
🚀 My Interview Experience at Birlsoft | Java & React | 3+ YOE  
  
Recently, I had the opportunity to interview with Birlsoft for a Java & React role. The discussion focused on Java internals, concurrency, problem-solving, and React fundamentals.  
  
Here are some of the key areas discussed:  
  
☕ Java & JVM  
  
* JVM Memory Model  
* Heap, Stack, and Metaspace  
* Garbage Collection and recent improvements  
* Internal working of HashMap  
* ArrayList vs LinkedList  
* What happens when a hash collision occurs?  
* @SpringBootApplication internals  
* @Component vs @Service  
* Understanding and resolving the N+1 query problem  
  
⚡ Concurrency  
  
* CompletableFuture  
* Asynchronous programming  
* Chaining asynchronous operations  
* Exception handling in asynchronous workflows  
  
🌊 Java Streams  
  
* Stream operations and practical use cases  
* Coding problem: Find the second duplicate/repeated element using Streams  
  
⚛️ React  
  
* What is React?  
* Class Components vs Functional Components  
* React Hooks and their usage  
  
The interview was a good reminder that strong fundamentals, practical implementation knowledge, and the ability to explain concepts clearly are all important during technical discussions.  
  
Sharing these questions to help fellow developers prepare for similar interviews.
