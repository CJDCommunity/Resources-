🚀 Intuit SDE-2 Frontend Interview Experience | 42 LPA | Bengaluru  
  
Think solving DSA problems is enough to crack a frontend engineering interview?  
  
Think again!  
  
This candidate-reported Intuit SDE-2 interview experience highlights something interesting: a dedicated Craft Demonstration Round, where your code quality, architectural decisions, and ability to extend an application live are put to the test.  
  
💰 Compensation Discussed: ~42 LPA  
📍 Previous CTC: ~28 LPA  
📌 Final Outcome: Rejected in the Hiring Manager Round  
  
🔥 Interview Process  
  
Round 1: JavaScript + DSA Mix (~1 Hour)  
  
* Two Sum, followed by Three Sum.  
* Implement memoization for any function.  
* How does Promise.all() preserve result order?  
* Promise.resolve() with non-promise values.  
* What can the replacer function in JSON.stringify() do?  
* bind() vs Arrow Functions for this.  
* useEffect dependency arrays and referential equality.  
* GraphQL Queries vs REST APIs.  
  
Round 2: Craft Demonstration (~1.5 Hours)  
  
This was the most interesting round!  
  
The candidate received a rough specification a day before the interview to build a Meeting Rooms application using React and GraphQL.  
  
During the interview:  
  
* Review your own code with the interviewer.  
* Extend the application with a new filter or field.  
* Explain code organization and folder structure.  
* Discuss state management and data persistence.  
* Explain component testing strategies.  
* Defend architectural and implementation trade-offs.  
* Identify what you would refactor with one more day.  
  
Round 3: JavaScript Deep Dive (~1 Hour)  
  
Round 4: DSA Problem Solving (~1 Hour)  
  
Round 5: Hiring Manager (~30 Minutes)  
  
🎯 What Makes This Interview Different?  
  
The Craft Demonstration round tests skills that traditional coding rounds may not fully capture:  
  
* Writing maintainable and readable code.  
* Making practical architectural decisions.  
* Understanding React and GraphQL.  
* Handling changing requirements.  
* Explaining and defending technical trade-offs.  
* Working with code written under time constraints.  
  
💡 My Key Takeaway  
  
Frontend interviews at this level aren’t just about JavaScript syntax or solving DSA problems.  
  
You must demonstrate that you can build, explain, extend, test, and maintain real applications.
