Preparing for your next Java Developer or Spring Boot interview? Save these questions for your preparation! 📌  
  
These questions go beyond definitions and test your understanding of Java internals, Spring container behavior, database performance, caching, and real-world backend scenarios.  
  
☕ 1. Core Java & Collections  
  
🔹 Compare wrapper class values using == and .equals(). How does Integer caching affect the output?  
  
🔹 ArrayList vs LinkedList vs HashSet vs TreeSet vs HashMap — use cases and time complexity.  
  
🔹 Explain lazy evaluation in Java Streams and the purpose of peek().  
  
🔹 Write a Java program to find the second-largest distinct integer.  
  
🔹 Solve the Two Sum problem.  
  
⚡ 2. Java Streams  
  
🔹 Calculate the total transaction amount for each customer using Java Streams.  
  
🔹 Sort customers by their total transaction amount in descending order.  
  
🌱 3. Spring Boot  
  
🔹 Explain the Spring bean lifecycle and Singleton vs Prototype scopes.  
  
🔹 What happens when two Spring beans implement the same interface and the interface is injected by type?  
  
🔹 ServiceA depends on ServiceB through constructor injection, and ServiceB depends on ServiceA. What happens during Spring Boot startup, and how can you resolve the circular dependency?  
  
🗄️ 4. JPA & Hibernate  
  
🔹 What is the N+1 query problem, and how do you solve it?  
  
🔹 Explain LazyInitializationException and how to prevent it.  
  
🔹 Optimistic locking vs pessimistic locking — when would you use each?  
  
🔹 How would you investigate and optimize a slow database query?  
  
🚀 5. API Design & Caching  
  
🔹 Design an idempotent payment API that prevents duplicate payments during retries. Explain the role of an idempotency key.  
  
🔹 An endpoint uses @Cacheable("products"). The product price changes in the database, but GET requests continue returning the old price. Why?  
  
🔹 Explain @CacheEvict and @CachePut.  
  
🧮 6. SQL & Database  
  
🔹 Write an SQL query to find the second-highest distinct salary.  
  
🔹 Explain how you would identify duplicate records and optimize database queries.  
  
🚨 7. Production Troubleshooting  
  
🔹 A Spring Boot API normally responds in 300 ms but suddenly takes 5 seconds when processing a large dataset. How would you investigate?  
  
Consider database execution plans, query count, N+1 queries, connection pools, memory usage, logging, and application metrics.
