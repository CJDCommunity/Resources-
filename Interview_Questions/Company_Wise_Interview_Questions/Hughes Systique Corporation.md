🚀 Java Developer Interview Experience | Hughes Systique Corporation (HSC), Gurugram 💻  
  
Recently, a Java Developer interview was conducted at Hughes Systique Corporation (HSC), Gurugram. The discussion covered Spring Boot fundamentals, transaction management, coding, and problem-solving.  
  
Sharing the questions to help fellow Java developers prepare for similar interviews. 👇  
  
🌱 Spring Boot & Technical Questions  
  
1. Introduce yourself and explain your technical stack.  
2. How can you override default properties in Spring Boot?  
3. What is @Profile in Spring Boot?  
4. How do you enable a specific Spring Boot profile?  
5. How do you enable logging in Spring Boot?  
6. What is the difference between @Component and @Service?  
7. What is @Repository, and how is it different from @Component?  
8. What are the different bean scopes in Spring?  
9. Why do we use transactions?  
10. How does @Transactional work internally?  
  
💻 Coding Questions  
  
1️⃣ Combination Sum  
  
Given an array of numbers and a target value, find all unique combinations of numbers that add up to the target.  
  
* Discuss the approach using backtracking/recursion.  
  
2️⃣ Second Smallest Element  
  
Find the second smallest number in an array without sorting it.  
  
* Approach: Single-pass traversal  
* Time Complexity: O(n)  
* Space Complexity: O(1)  
  
📌 Interview Takeaway  
  
Strong fundamentals matter. Understanding the why behind concepts like transactions, bean scopes, Spring profiles, and backtracking is just as important as knowing the syntax.  
  
	Every interview is an opportunity to learn, identify gaps, and improve your preparation.
