Delhivery Interview Experience | Java Full Stack Developer 🚀

A few weeks ago, I interviewed with Delhivery for a Java Full Stack Developer position, and I wanted to share my experience to help others preparing for similar roles.
The interview process included an HR screening followed by two technical rounds.

🧩 Round 1 – Technical | Java + DSA + System Design Basics
This round was a combination of theoretical discussions and DSA problem-solving. The interviewer was friendly and allowed me to think aloud while approaching the problems.

Backend & Architecture
1. Where would you choose Monolithic architecture, and where would you choose Microservices?
2. What are the drawbacks of Monolithic architecture?
3. What are the drawbacks of Microservices?
4. Difference between Monolithic and Microservices architecture.

Core Java / OOP
5. What is OOP? Explain its core principles.

Kafka
6. How does Apache Kafka work?
7. What are Consumer Groups?
8. What are acknowledgements (acks) in Kafka?

Elasticsearch
9. What is Elasticsearch, and where is it used?

Database
10. What are ACID properties?
11. Difference between SQL and NoSQL databases.
12. Where would you prefer SQL, and where would you prefer NoSQL?

Spring / Hibernate
13. What is @Transactional in Spring Boot, and what is its purpose?
14. What is Transaction Isolation?

🧠 DSA Section
The interviewer allowed me to choose a topic I was comfortable with and then asked two problems.

Problem 1 – Linked List
You are given the head of a linked list and an integer array nums.
Return the number of connected components formed by nodes whose values appear in nums.
Example:
Input:  head = [0,1,2,3]
nums = [0,1,3]
Output: 2

Problem 2 – Find Duplicate in a Read-Only Array
The array cannot be modified.
Size = N + 1
Values range from 1 to N
Find any duplicate
Time Complexity: O(N)
Space Complexity: O(1)
Example:
Input:  {10,1,2,3,5,4,9,8,5,6,4}
Output: 5
Overall, I finished this round with decent confidence.
