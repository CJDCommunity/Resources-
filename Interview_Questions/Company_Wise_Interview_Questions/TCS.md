
🚀 TCS Java Full Stack Developer Interview Experience | 6 YOE 💻  
  
Sharing questions from a recent TCS Java Full Stack Developer interview for a candidate with 6 years of experience.  
  
The interview covered Core Java, Java 21, Multithreading, Spring Boot, Microservices, Kafka, and Coding.  
  
🔥 Technical Interview Questions  
  
☕ Core Java & Multithreading  
  
1. synchronized vs ReentrantLock — what are the differences?  
2. HashMap vs ConcurrentHashMap. Explain HashMap internals.  
3. Abstract class vs Interface.  
4. What are intermediate and terminal operations in Java Streams?  
5. What Java 21 features have you used in your project?  
6. Project Loom vs traditional threads.  
7. How do you bind properties from [application.properties](http://application.properties/) to nested Java classes?  
8. Explain 1D and 2D arrays.  
  
🌱 Spring Boot & Microservices  
9. Explain the use of API Gateway, Service Discovery, Saga Pattern, and Circuit Breaker.  
10. How would you maintain data consistency if one service fails while processing a transaction?  
11. How do Spring Boot annotations work internally?  
  
🚀 Kafka & Production Scenarios  
12. How does a Kafka consumer handle millions of transactions?  
13. How can an event-driven architecture maintain high throughput if a broker fails?  
14. How would you troubleshoot high CPU utilization in an application?  
  
💻 Coding Questions  
  
1️⃣ Merge Two Sorted Arrays In-Place  
  
Given two sorted arrays, merge them into one sorted array in non-decreasing order.  
  
The first array has enough extra space to hold the elements from the second array. Store the merged result in the first array without returning a new array.  
  
2️⃣ Reverse a String Using Streams  
  
Reverse a string using Java Streams without using StringBuilder or built-in reverse methods.  
  
3️⃣ Count Fruit Occurrences  
  
Given a list of fruits, find the occurrence count of each fruit.  
  
⸻  
  
💡 Interview takeaway: Preparing definitions alone isn’t enough. Be ready to explain internal workings, discuss real project implementations, solve coding problems, and troubleshoot production scenarios.
