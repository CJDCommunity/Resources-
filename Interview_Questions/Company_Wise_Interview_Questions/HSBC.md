🎯 Tricky Follow-up Questions You Should Prepare  
  
1. Your compareTo() sorts employees by salary. Two employees earn the same salary. Why does TreeSet keep only one?  
2. Why does ConcurrentHashMap throw an exception for a null key while HashMap accepts one?  
3. Eight threads execute get(), increment the value, and put() on the same ConcurrentHashMap key. Why can the final count be incorrect?  
4. Java 21 introduced three interfaces to the Collections Framework. Can you name them?  
5. Why does "hs" + "bc" == "hsbc" return true, but using a String variable can return false?  
6. Who decides whether Spring Security returns HTTP 401 or 403?
