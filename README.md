# Community Resources

Welcome to the official resource repository for our community.

This repository serves as a centralized hub for learning materials, documentation, interview preparation content, roadmaps, templates, and useful references shared within the community.

## 📚 What's Available?

- Java
- Spring Boot
- Microservices
- SQL
- Docker & Kubernetes
- System Design
- DSA
- Interview Experiences
- Resume Templates
- Roadmaps
- Cheat Sheets
- Useful Links

## 📌 Repository Purpose

This repository is designed to organize and index community resources. Large files such as books, recordings, and presentations may be hosted externally (e.g., Google Drive) and linked from this repository.

## 🤝 Contributing

Community members are welcome to contribute valuable resources. Please ensure that:
- Resources are placed in the correct category.
- Duplicate content is avoided.
- Proper credits and licensing are respected.
- Content is relevant and useful to the community.
